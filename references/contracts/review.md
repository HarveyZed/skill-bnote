# 派单：讲义内容审阅（bnote 契约 review v1）

你在审阅**已有产物**，不写正文。工作目录：{{OUT_DIR}}，这是第 {{ROUND}} 轮审阅。

## 审什么

范围：{{SCOPE_DESC}}
重点：{{FOCUS_DESC}}

**脚本已经检查过结构**（章界、时间轴、图是否存在、keypoints 条数…），那些不用你重复。你只找**脚本查不出来的内容问题**：

1. **漏讲**：字幕讲了、讲义没写（对照 `transcript.md` 的对应时间窗）；
2. **编造**：讲义写了课程没讲的内容（含把常识当成"讲师说的"）；
3. **图注错**：图注与图不符（要自己**打开图看**——DSH 里用 `read_image`，其它 harness 用等价的读图工具；不要信 OCR 文本）；
4. **口径不一致**：同一概念/数字/名称在不同章说法不同。

## 你要交付的东西

把发现写进 `{{FINDINGS_PATH}}`（JSON 数组，一个发现一条）：

```json
[
  {
    "scope": "L1",
    "owner": "chapter:06",
    "severity": "major",
    "evidence": "06-xxx.md:42 与 transcript 10:23-10:41",
    "what": "一句话说清问题",
    "fix_hint": "该怎么改（给写手的具体指令）"
  }
]
```

**scope 必填，按影响面选**（决定后面怎么处理，选错会导致整集返工）：

| scope | 含义 | 判定信号 |
|---|---|---|
| `L1` | 单章内容问题 | 只涉及一章 |
| `L2` | 跨章不一致 | 同一因由出现在 ≥2 章（术语、口径、称呼） |
| `L3` | 章界问题 | 一节内容横跨两章，或一章里塞了两个无关主题 |
| `L4` | 时间轴问题 | 时间行与 slides.json 对不上、小节时间与字幕内容不符（→ pipeline 跑 `bnote retime`，零 token） |
| `L5` | 管线问题 | 图本身错（切错页）、字幕有缺口 |
| `L6` | note 问题 | 落在 `note.md` 上 |

`severity`：`major`（会被读者发现/影响理解）或 `minor`（措辞、可改进）。
**只有 major 会被回派给写手**，minor 记录在案即可。宁可少报几条真的，也不要凑数。

## 不许做的事

- 不修改任何正文文件（你只写 findings JSON）；
- 不为"让校验通过"而提结构性建议；
- 不因个人风格偏好判定"编造"——要有字幕依据。

## 回报格式

发现总数、各 scope 条数、你认为最值得先修的两条（一句话理由）。
