## 你产出什么

`{{OUT_DIR}}/text/NN.md` —— 每块一个文件，**纯正文 Markdown**：

- 段落标题写成 `## [00:12:30] 自己拟的小标题`：锚点**必须**用素材里给的那个（工具打的）；
  可以合并相邻段落（同一话题连贯时），**合并后用被合并段落里【最早】那一段的锚点**（用中间或靠后的锚点会把内容标到更晚的时间上，
  校验会以「首句来自更早的段落」给出警告）；
- 正文把该段字幕改写成**书面中文**（不是逐字转写）：补标点、断句、必要时调整语序；
- **删掉口语填充与重复**（嗯 / 啊 / 就是说 / 这个这个 / 那个那个，以及结巴与自我更正），口误直接修顺；
- **书面化 ≠ 压缩**：不许删例子、数据、步骤与细节；不许把几段并成一句结论；不许跳过听不清的地方（听不清照实标出）；
- **可判据**：读者对照字幕能**逐句看出对应关系**——润色到“看得出没脱离原稿”为止；
- 允许做：合并碎句、把并列要点写成列表、按话题分段、给每段拟小标题；
  不允许做：改事实与数字、改讲师的结论与强调、补讲师没说的内容。

## 硬性约束

- **事实来源只有字幕与人写的元信息**：讲师没说的不写；你自己的推断必须标「（推断）」；
- **字幕不是准绳**：平台 AI 轨与 UP 上传的 CC 都是语音识别、都可能没校对。判断用字时优先看**人写的元信息**（标题/简介/标签）；
  冲突或拿不准就就地括注存疑（例如音近疑为某词），**不要**因为字幕里出现某写法就认定它对，也不要静默统一；
- **推断出来的更正与无法归位的存疑，要在相关段落之后就地表注**（信息流没有 corrections 台账，这一条是给读者的）：
  引用块内**每条一行、用列表**，「校对」两字写全：

  ```markdown
  > **【校对】**
  > - 字幕「long chain / long cha / long chan」→ LangChain；依据：人写的分P 标题「【Agent框架】24. LangChain课程介绍」
  > - 字幕「在 WRC 上」→ 在 RAG 上；依据：同段自述「广义的 RAG 的应用流程」
  > - 字幕「两个月 / 两年」照原样保留；依据：字面自相矛盾，无法判定
  ```

  位置在段落**之后**、自成一段，不插进句子中间；有元信息或上下文硬依据、改法无歧义的常用写法**不必**标注。
- **不编造**：人名、机构、产品名、数字一律不许补（数字拿不准就保留原样并标注）；

## 插图（只有派单给了候选插图时才用）

候选插图在 `_meta/figures/NN.png`，清单 `_meta/figures.json` 记着每张的时刻与来源帧。
路径**相对交付稿 `lecture.md` 所在的目录**（也就是本次的工作目录 `{{OUT_DIR}}`）——
写 `_meta/figures/NN.png`，**不要**写 `../_meta/figures/NN.png`：那是相对 `text/NN.md` 的形态，
拼进 `lecture.md` 后会指向 `out/_meta/…`（不存在），校验会当场报错。
**只在关键处引一张**，三条同时满足才算关键时刻：
1. 画面里有**与口播指涉一致的可见对象**（界面 / 图表 / 代码 / 演示结果 / 流程图 / 公式）；
2. 该对象**用文字说清会明显更长或更容易失真**（一串参数、一张流程图、一段代码）；
3. 不是纯人像、纯滚动、过渡画面或与前后文无关的装饰；**画面里有临时 UI 弹层也不算**——
   菜单 / 右键菜单 / 提示框 / 鼠标提示（tooltip）是讲解过程中的临时覆盖层，不是被指涉的对象，
   出现它们这一帧就不是关键时刻（某一集的 `03.png` 正是这类：主体参数块虽可见，但一帧里浮着右键菜单，
   从严口径不引；被引对象被弹层压住时更不能引）。

**没有合适的就不引**——0 张完全合格（为了配图而配图是错的）。写法：

`![他在这里演示的是 Xxx（一句话）](_meta/figures/01.png)`，紧跟相关那一段之后；
说明写“他在演示什么”，**不要**写“画面截图/如图”。
